# Local Beads tracker

This repository uses embedded Beads with the `pplx` issue prefix.

Read `../docs/agents/issue-tracker.md` before creating, claiming, closing,
or syncing tickets. Local Beads is authoritative; GitHub Issues is a manual
push-only mirror. Dolt federation and automatic sync are disabled.

The local database is ignored by Git. Tracked configuration is not a backup
of ticket contents. Authentication tokens belong in the invoking environment,
not this directory.
